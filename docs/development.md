# Development environment

Run `devenv shell` at the repository root to enter the Rust nightly pinned to 2026-09-20. [`devenv.nix`](../devenv.nix) is the only devenv configuration file. It reads the locked rust-overlay revision from [`flake.lock`](../flake.lock); `devenv.lock` pins devenv's own inputs. [`rust-toolchain.toml`](../rust-toolchain.toml) and the package [flake](../flake.nix) use the same nightly date. [`.cargo/config.toml`](../.cargo/config.toml) passes `-Zpolonius=next` for workspace builds, so Cargo uses the Polonius Alpha borrow checker. The shell provides Cargo, rustc, rustfmt, Clippy, rust-analyzer, Nix, Git, Just, jq, Bash, coreutils, awk, Meson, Ninja, CMake, pkg-config, and zstd. Rust [announced Polonius Alpha on nightly](https://blog.rust-lang.org/2026/08/04/enabling-polonius-alpha-on-nightly/); the pinned date and explicit compiler flag keep this project on that checker while it remains experimental.

Run `just` to list recipes. `just fmt-check` checks formatting, `just check` type-checks the workspace, `just test-fixtures` runs the copied CppNix fixture checks, and `just test` runs the full workspace suite. `just ci` runs formatting, checking, and the full suite in sequence.

Run `just nix-tests-update` to fetch the latest numbered stable official Nix source and tests into the ignored `tests/upstream/nix-official/` checkout. The command updates `tests/upstream/nix-official.lock` with the exact tag and commit. Run `just nix-tests-sync` after cloning this repository to restore that revision. The fixed 2.36.0 fixtures used by the Rust compatibility tests remain under `tests/upstream/nix/`; updating the official checkout does not rewrite them. Run `just nix-snapshot-verify` to check those fixtures against the object IDs recorded for their upstream commit, or `just nix-snapshot-verify upstream` to also compare with the fetched commit. [Upstream test workflow](../tests/README.md)

The imported `nix-compat-derive-tests` trybuild UI snapshots were captured under Rust 1.95. On the pinned nightly, some diagnostics differ and `deserialize_enum_non_exaustive.rs` triggers a rustc internal compiler error in borrow checking. Do not bless the ICE into a snapshot. `just test-core` skips that UI snapshot crate while the compiler issue is investigated; it does not replace `just test` as the complete check. The copied CppNix shell and NixOS VM tests still need dedicated runners, as described in [verification](verification.md).

Run `devenv shell -- just ci` for the complete Rust workspace. It currently fails at the imported UI test because the pinned compiler hits the ICE above; formatting and workspace checking pass, and the preview CLI has its own passing tests. Keep any nightly-specific UI snapshot changes separate from compatibility logic so reviewers can see which diagnostics changed.
# Pure evaluator comparison

Use `just eval-compare /path/to/nix-instantiate /path/to/report.json` from `devenv shell` to compare a small pure-expression corpus against an explicitly selected CppNix executable. The command writes a JSON report and fails if exit codes, stdout, or stderr differ. Record the reference revision separately when using this for compatibility evidence; the host Nix version may differ from the target 2.36.0 release. See [verification](verification.md).

# Development environment

Run `devenv shell` at the repository root to enter the Rust nightly pinned to 2026-09-20. [`devenv.nix`](../devenv.nix) is the only devenv configuration file. It reads the locked rust-overlay revision from [`flake.lock`](../flake.lock); `devenv.lock` pins devenv's own inputs. [`rust-toolchain.toml`](../rust-toolchain.toml) and the package [flake](../flake.nix) use the same nightly date. [`.cargo/config.toml`](../.cargo/config.toml) passes `-Zpolonius=next` for workspace builds, so Cargo uses the Polonius Alpha borrow checker. The shell provides Cargo, rustc, rustfmt, Clippy, rust-analyzer, Nix, Git, Just, jq, Bash, coreutils, awk, Meson, Ninja, CMake, pkg-config, and zstd. Rust [announced Polonius Alpha on nightly](https://blog.rust-lang.org/2026/08/04/enabling-polonius-alpha-on-nightly/); the pinned date and explicit compiler flag keep this project on that checker while it remains experimental.

Run `just` to list recipes. `just fmt-check` checks formatting, `just check` type-checks the workspace, `just test-fixtures` runs the copied CppNix fixture checks, including every language fixture against the evaluator ([outcome table](verification.md)), and `just test` runs the full workspace suite. `just ci` runs formatting, the offline snapshot check, type checking, and the full suite in sequence.

The local tests also cover behavior outside the copied Nix suite. `cargo test -p nix-rs-cli --test cli` checks the preview command's arguments, strict evaluation, file handling, and exit codes. `cargo test -p nixrs-compat-tests --test differential_eval` checks the comparison runner with mock executables, including its isolated environment, JSON report, mismatch handling, and version failure. These tests need no CppNix executable. The runner tests use POSIX shell mocks and run on Unix.

Run `just nix-tests-update` to fetch the latest numbered stable official Nix source and tests into the ignored `tests/nix-official/` checkout. The command updates `tests/nix-official.lock` with the exact tag and commit. Run `just nix-tests-sync` after cloning this repository to restore that revision. The fixed 2.35.2 fixtures used by the Rust compatibility tests remain under `tests/nix/`; updating the official checkout does not rewrite them. Run `just nix-snapshot-refresh` afterwards to copy the checkout's test paths into `tests/nix/` and rewrite `tests/nix-snapshot.lock`. Run `just nix-snapshot-verify` to check those fixtures against the object IDs recorded for their upstream commit, or `just nix-snapshot-verify upstream` to also compare with the fetched commit. [Test snapshot](verification.md#test-snapshot)

The imported `nix-compat-derive-tests` trybuild UI snapshots were captured under Rust 1.95 and have been updated for the pinned nightly's diagnostics. `deserialize_enum_non_exaustive.rs` used to trigger a rustc internal compiler error; `nix-compat-derive` now reports the uncovered version before generating the code that crashed the compiler. Never bless a compiler crash into a snapshot. `just test-core` skips the toolchain-sensitive UI snapshot crate for quick runs; it does not replace `just test` as the complete check. The copied CppNix shell and NixOS VM tests still need dedicated runners, as described in [verification](verification.md).

Run `devenv shell -- just ci` for the complete Rust workspace; it passes on the pinned toolchain. Keep any nightly-specific UI snapshot changes separate from compatibility logic so reviewers can see which diagnostics changed.
# Pure evaluator comparison

Run `just reference` to build the pinned CppNix 2.35.2 reference at `target/nix-reference`. The flake input `nix-reference` locks tag `2.35.2` without overriding its inputs, so the package is upstream's own build and is fetched from cache.nixos.org. Run `just eval-compare-reference` to compare the preview evaluator with it, or use `just eval-compare /path/to/nix-instantiate /path/to/report.json` from `devenv shell` to compare a small pure-expression corpus against another explicitly selected CppNix executable. The command writes a JSON report and fails if exit codes, stdout, or stderr differ. Record the reference revision separately when using this for compatibility evidence; the host Nix version may differ from the 2.35.2 reference. See [verification](verification.md).

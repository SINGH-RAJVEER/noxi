# and tests/nix/tests, checked by tests/fixture_inventory.rs.
#
# Each line is `<class> <glob> [# note]`; the first matching line wins. Paths are
# relative to tests/nix. `**` matches any number of directories, `*` matches within
# one path segment. Every pattern must match at least one file.
#
# Classes:
#   table:<test>  The named test in crates/compat-tests/tests lists each file itself
#                 with its expected outcome (pass, known gap, or reference anomaly).
#   pass:<test>   The named test reads the file and passes.
#   gap           A nix-rs test reads the file and records a known failure.
#   anomaly       The reference's own behavior for this file is anomalous; see the note.
#   unrun         No nix-rs test reads the file yet.
#   ignore        Not a fixture: placeholders and generator scripts.
